# 📊 Customer Churn Analysis Dashboard

## 📌 Overview

Built an interactive **4-page Tableau dashboard** to analyze customer churn across demographics, service plans, payment methods, customer contracts, and geographic regions.

The dashboard enables stakeholders to identify churn drivers, monitor KPIs, and support data-driven customer retention strategies.

---

## 🛠 Tools Used

- Tableau
- SQL
- Python

---

## 📈 Dashboard Features

- Executive KPI Dashboard
- Geographic Analysis
- Customer Segmentation
- Cross Filtering
- Parameter Controls
- Heatmaps
- Drill-down Visualizations

---

## 💡 Key Insights

- Month-to-month contracts have the highest churn rate.
- Competitor offerings are the primary reason for customer churn.
- Older customer segments exhibit higher churn.
- Contract type and payment method strongly influence customer retention.
